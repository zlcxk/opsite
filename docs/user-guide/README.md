# Opsite 用户手册

本手册面向 Opsite `0.1.0` 的使用者，说明如何安装、配置和使用当前版本已经实现的功能。

- 适用版本：`0.1.0`
- 最后更新：2026-11-01
- 文档中的界面名称、按钮和状态值以当前代码为准。
- 截图来自实际运行的 Opsite 实例，已去除浏览器地址栏和部署信息。

> Opsite 是单用户、无登录的本地应用。安装和使用前请先阅读仓库根目录的 [SECURITY.md](../../SECURITY.md)。

## 文档约定

- 界面名称、按钮和状态值使用「」标注，尽量与页面一致。
- 代码、路径、环境变量和命令使用行内代码或代码块。
- 所有文档和截图使用仓库相对路径。
- 不写入临时部署域名、真实邮箱、Token、密码、内部 IP 或个人数据。
- 规划中的能力会明确标注为“计划中”，不会写成已实现功能。

`docs/assets/screenshots/` 中的截图来自实际运行页面，使用公开软件和公开漏洞数据，不包含浏览器地址栏、部署域名、账号、Token 或私人笔记。

## 遇到问题

- 安装和启动问题：先看[安装与首次启动](02-installation.md)的“常见启动问题”。
- 数据采集、数据源健康、SMTP 和备份问题：看[运行中心、设置与故障排查](14-operations-settings.md)。
- 安全问题和敏感数据：不要公开提交 Issue，按 [SECURITY.md](../../SECURITY.md) 的流程私下报告。
- 功能缺陷和文档错误：通过仓库 Issue 提交。
