## 开发入口

```bash
npm ci
cp .env.example .env
npm run dev
```

- 前端开发服务器：`http://127.0.0.1:5173`
- API：`http://127.0.0.1:8787`
- 测试：`npm test`
- 类型检查与构建：`npm run build`、`npm run build:server`

## 文档约定

- 描述当前代码实际行为，不依据旧 PRD 或提交标题推断能力。
- 明确标注限制、未实现项和失败路径。
- 代码示例优先使用仓库内真实路径和命令。
- 不写入临时部署域名、真实凭据、内部网络或个人数据。
- 修改接口、环境变量、表结构或发布流程时，同步更新本目录文档。
