生产模式冒烟使用临时数据目录和本地构建产物：

```bash
DATA_DIR=<临时目录> CLIENT_DIR=dist/client \
PORT=8790 HOST=127.0.0.1 DISABLE_SCHEDULER=true \
node dist-server/server/index.js
```

结果：

- `/api/health` 返回 `200` 和 `{"ok":true,...}`；
- `/` 返回 `200`，内容为前端入口；
- `/software` 返回 `200`，SPA fallback 正常；
- `/api/nope` 返回 `404` 和 JSON 错误；
- 临时数据库正常创建，进程可正常停止。

首次冒烟未设置 `CLIENT_DIR`，根路径返回 404，原因是编译后默认查找 `dist-server/dist/client`。该行为已写入文档，未修改代码。

测试环境为 Node `v23.11.0`、npm `10.9.2`。Node 23 不在项目支持范围内，正式发布应在 Node 22.12+ 或 24 LTS 上重新执行测试和构建。
