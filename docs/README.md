## 文档约定

- 文档默认使用中文；命令、代码、配置项保留原文。
- 使用仓库相对路径引用其他文档和截图。
- 不写入临时部署域名、真实邮箱、Token、密码、内部 IP 或个人数据。
- 截图必须来自实际运行页面，并经过脱敏。
- 规划中的能力必须明确标注为“计划中”，不能写成已实现。
